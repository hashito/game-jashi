# 企画メモ：邪視 ― 視線の山（5.0 標準版）

2026-11-02 作成。game-kit の [作る順番](https://github.com/hashito/game-kit/blob/main/docs/build-order.md) の S0。
4.3.0 までの独自エンジン版（`dist/`）を、game-kit の 3D 標準 1.9 で作り直す。物語・地図・規則は 4.3.0 を引き継ぎ、八尺様で行った改善（Game-fleet `docs/feedback-checklist.md`、`_feedback/hasshaku.md`）を全部当てる。

## 1. 一行で

- 題名（決定）／英題：邪視 ― 視線の山 ／ Jashi: The Mountain of the Gaze
- 一行の売り（site.json の description の元。50〜200字）：叔父の別荘の二階、ベランダの望遠鏡で見てしまった白い姿。目が合えば心を削られ、近づかれれば鎌が振り下ろされる。視線を切り、雨戸と無線と残された記録を頼りに、日が暮れる前に山を下りる一人称 3D ホラー。
- 題材・元になった話（ある場合。出典と、どこを変えるか）：投稿怪談「邪視」の翻案。山で見てはいけないものを見る、目が合うと正気を失う、の骨組みだけを借り、人物・場所・道具・結末は創作（4.x と同じ）。

## 2. 主人公と目的

- 主人公は誰か・職業・年齢（知っていることと、まだ知らないこと）：「私」、二十代。叔父の修司が手放す山の別荘の片付けを手伝いに来た。古い DV カメラで、持ち帰る備品を撮っている。子供の頃に亡くなった弟・航のことは、結末まで語らない。
- なぜここに来たか・なぜ帰らないか（K-03）：片付けの手伝い。叔父が林道の車へ荷物を積みに出たあと、倒木で道がふさがる。叔父は麓へ助けを呼びに行き、私は一人で駐車場の車まで戻るしかない。
- 最後に理解すること／達成すること：山には、帰れなかった人の「帰り」がまだ続いている（作業札・長靴・帳面）。叔父は昔、私と航を連れて帰ったことがある。車で山を下りる。
- 最初から持っている道具（仕事で来たなら手ぶらにしない。I-01）：DV カメラ（撮る・記録を見返す）、修司から借りた無線、懐中電灯。

## 5. 怖さ・手応え

- 怪異のルール（何をすると危ないか・どう逃げるか。E-05 / E-07）：次のとおり。
  - 邪視（白い肌、額に縦の一つ目、鎌）と目が合っている間、心（正気）が減る。0 で死ぬ。サングラスで減り方は半分以下、遠いと小さい。
  - 目を閉じる（Q、タッチは「目を閉じる」ボタン）と、ゆっくりしか歩けないが回復が速い。物陰・屋内でも回復が速い。
  - 近づかれると鎌を振り上げる（1 秒の予備動作と音、画面の縁にその向き）。当たると体力の 3 分の 1。背後からは振り始めない。
  - 見失った相手の今の場所は知らず、最後に見聞きした場所を探す。鐘の音に引き寄せられる。
- 最初の遭遇は教える場面にする（E-01）：望遠鏡の映像で姿を見る。二階の窓の向こうに立つが入ってこない（無線の同調までは別荘の外で待つ）。そこで「窓から離れろ」「雨戸を引け」と教わる。
- 手応えのある判断・操作（ミニゲームの候補。docs/minigame-library.md から選ぶ）：望遠鏡を撮る `photo-focus`、雨戸を引く `steady-hand`、無線の同調 `tune-radio`、ボトル二本を選ぶ `sort-items`、呼び鐘の音止め `timing`、暗い小屋でハンドルを探す `search-dark`、避難小屋で気配が過ぎるまで息を止める `hold-breath`、ゲートの巻き上げ `pump-gauge`、エンジンの始動 `timing`。

## 6. 範囲

- 部屋の数・屋外の有無：屋内は別荘一階（玄関・無線机、寝室）、二階（作業室、納戸）とベランダ、物置、避難小屋。屋外は林道、伐採跡、沢沿い、橋、駐車場。4.x と同じ座標（65 × 66 m）。
- 話す人（顔写真が要る。A8）：修司（対面・無線）と私。電話の声（航）は名乗らない。
- 1回の目標プレイ時間：10〜15 分
- PC／スマホ：両方（標準）
- 公開先：jashi.autoarticles.net、Firebase（jashi-hashito）、GA4（G-MKTNWD1KZT）

## 7. 決めないこと（あとで決める）

- 写真の追加の枚数（冒頭・結末・場所）。S3 で、足りない物だけローカルで作る。
- 声（無線の修司・電話の声）。S3 で VOICEVOX を使えるか確かめてから。
