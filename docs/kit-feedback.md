# キットへの要望（邪視 5.0.0 から）

## キットへ移した物

- `world-from-plan`：部屋の灯りの上限（16）を、天井のある部屋だけで数える。外の部屋が数に入って、屋内が暗くなっていた。
- `world-from-plan` と `recipes`：戸口の上の壁（まぐさ）に `userData.lintel` を付け、部屋の壁紙を塗る。
- `check-select-range`：階のある間取りでは、選ぶ位置にも階を入れる。
- smoke の雛形：近づく位置に階を入れる。階段は戸として扱わない。「続きから」は起動の完了を待ち、押す前に画面の中へスクロールする（横向きのスマホでは、タイトルの枠がはみ出す）。
- `monsters.json` の `kill: { by, reach }`：接触ではなく自前の攻撃で殺す怪異のための項目。`check-escape` は、届く距離を捕まる距離として再生する。視界より手前で見失う設定（`lose.dist` が `sight` より短い）も警告する。

## 標準にできそうな物（まだ作品の中にある）

- 視線の帯（`js/ext/gaze.js`）：視線が通るかの判定、視野の円錐、遮る物（壁・床・閉じた戸・雨戸）。目を閉じる操作とあわせて、「見てはいけない」怪異に使える。
- 振り上げてから当たる近接攻撃（`js/ext/rules.js` と `gaze.js`）：警告の時間をフレームレートに依らず保証し、振り上げている方向を画面の端で知らせる。
- 投げて怯ませる道具（ボトル）：放物線、怯み、怪異を見失わせる処理。
- まとめて描く森（`js/ext/mountain.js`）：杉を2種類のインスタンスで描き、枝が部屋の矩形に入らないようにする。`building.forest` は一本ずつメッシュを作るので、数が多いと重い。
- 作業の `run()` から小さな遊びを呼ぶ処理：`ctx.runMinigame` がないので、`story.js` に `playMG` を持っている。
