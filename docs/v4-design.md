# v4 改修の設計判断

## マップ

別荘の二階、ベランダ、一階、実階段と屋外を同じ座標系で結ぶ。開始時は修司を正面に置き、望遠鏡へ向く動作で日常から森へ視点を移す。階段と床は描画・衝突・視線・敵の経路探索・地図に共通のデータを使う。

西は伐採跡、東は沢沿い、南は別荘と林道。材木、石積み、標識、灯りで見分ける。東に戻り道を加え、西の鐘には視線を切る材木と遮蔽板を配置する。鐘から遮蔽へ退き、周回路へ抜けられる幅を確保する。

杉は樹皮を持つ幹、木質の枝、垂れた針葉の段で構成する。透明な枝葉の下に不透明な下地を塗らない。互換描画でも霧と光は葉の不透明ピクセルに適用する。

## ストーリーと会話

片付けのための備品撮影を出発点にする。修司は二階で対面して頼み、主人公が望遠鏡を覗く間に実際の階段から林道へ出る。以後は無線となり、倒木を除いて道を開け、麓で助けを呼ぶ役割を持つ。

風景、白い背中、顔の振り向き、雨戸、階下の混信、同調、サングラス、小物の関係、脱出の順に情報を出す。先に道具を取っても未提示の説明は順番に届ける。新規プレイは無線の同調まで先の章を開示しない。旧セーブは既存の章を後退させない。

会話カードは肖像、名前、関係、対面／無線、所在を表示する。主人公は一人称のカメラ図柄で区別。短文でも6秒、長文は最大14秒確保し、Tでゲームを含めて停止、Enterで送り、履歴で再読できる。対面の台詞を望遠鏡後の無線として再生しない。

## ギミック

| 道具 | 目的 | 実際の規則 |
| --- | --- | --- |
| 二階の雨戸 | 視線を切り、窓から離れる判断を作る | 閉じると上階の通行と視線を遮る。引手は両側から使える。一階玄関は開いたまま |
| 机の無線 | 修司の所在と救助の段取りを段階的に伝える | 0〜100の同調つまみから受信位置を探し、1.2秒安定してから固定。画面を閉じると連続雑音も停止 |
| 林業用の呼び鐘 | 遮蔽物と敵の聴覚を使って逃げる | 音の半径65m、余韻の記憶5秒、再使用25秒。見えている相手を優先し、姿を見失ってから残る響きを一度調査 |

鐘はその場で鳴らして離れる道具。小物として調べる弟の鈴とは用途を区別する。雨戸と鐘を使った判断は、生還後の短い会話にも反映する。

## 怪異

顔だけを暗い写真で覆わず、頭と身体に同じ灰白色の皮膚を使う。縦の単眼、厚く非対称なまぶた、眼窩、頬骨、奥の口腔、ずれた顎、不揃いの歯、首の腱、爪、鎌の厚みを実体のある形にする。顎、目、喉を、呼吸・視認・攻撃・怯みに連動させる。

移動は視野と音の情報に従う。見失った相手の現在位置を知っているようには動かず、最後に見聞きした場所を探す。首と腰の追従にずれを作り、足元へ灯りを向けると低い姿勢で覗き込む。攻撃は鎌を上げる予備動作、振り抜き、戻りに分け、距離や角度による回避を成立させる。

## 音と映像

風、杉葉、床、階段、落葉、砂利、金属、喉、息、無線を別の音色として合成する。怪異の足音は実移動から発音し、停止やその場の方向転換では足音を出さない。視点に対する左右、距離、壁、階で定位と帯域を変える。メニュー・読書停止では連続音をフェードし、再開時に現在の状況へ戻す。

VHSの乱れは危険と接触に連動。顔の近接フレームには立体モデルと同じ単眼・白肌・歪んだ顎の生成画像を使う。常時の乱れ、揺れ、音量は設定できる。台詞は読みやすい文字で表示し、音声収録や音声合成の読み上げは使用しない。

## 確認範囲

自動検証では実装本体の物語、進行、保存移行、敵AI、衝突・経路、攻撃・死亡・脱出、音ノード、会話カードを検証する。描画と音の境界を置き換えたテストと実ブラウザの操作確認は区別する。実機スマートフォン、WebGLの実表示、実音の主観的試聴はこの環境では未検証。

## 4.0.1 初回プレイテスト後の調整

初見のプレイテストで、望遠鏡のあと一階の無線に着く前に10回以上死亡した。恐怖は残し、理不尽さを取り除く。AIは書き換えず、数値と境界条件で調整する。

| 項目 | 4.0.0 | 4.0.1 |
| --- | --- | --- |
| 序盤の怪異 | 望遠鏡後すぐ別荘へ入り、階段で鉢合わせる | 別荘中心から半径14mの外で止まり、見える位置で待つ（`enemy.js` の leash）。無線の同調で解除。二階で90秒、一階で90秒を超えて留まると解除される |
| 邪視の減り方 | 毎秒23.5（サングラス9.2） | 毎秒10.5（サングラス4.2）、24mより遠い相手は0.55倍。回復は毎秒3、目を閉じる・遮蔽で毎秒7 |
| 鎌 | 予備動作0.88秒、54ダメージ（2回で死亡）、届く距離＋0.55m | 予備動作1.05秒・画面警告と音、34ダメージ（3回で死亡）、届く距離＋0.3m、カメラ背後（約±105°の外）からは振り始めない、攻撃後の間1.1秒 |
| やり直し | 記録した位置と向き、怪異もそのまま | 壁から0.8m以上離れた開けた位置（階段内を除く）、経路の方向を向く。怪異は26m以上離れた見えない地点へ移り、プレイヤーの位置を忘れる。5秒間は邪視と鎌が止まる |
| 雨戸 | ベランダ側で閉めると外に残る | ベランダで閉めると部屋に入ってから閉める |
| 方角表示 | 壁越しの直線距離 | A*経路で直進できる最も先の点を指し、経路の長さを表示。机の上の物は、使える立ち位置へ案内。望遠鏡後は階段上に灯りと床の矢印 |

## 4.0.2 二回目のプレイテスト後の調整

二回目のプレイテストでは生還まで到達できたが、会話の遅延、背後からの鎌の向きが分からないこと、出入口が一つの小屋で逃げ場がないことが目立った。恐怖は残し、情報の出し方を整える。

| 項目 | 4.0.1 | 4.0.2 |
| --- | --- | --- |
| 会話の待ち行列 | 際限なく溜まり「続き 10」以上。場所の台詞が遠くで流れる | `dialogue.js` の `pruneSpeechQueue`：筋（critical）は保持、場所（context）は発生地点から14m・別の階・24秒で破棄、反応（ambient）は6秒で破棄。場所と反応の待ちは2件まで（古いものから破棄、critical は数えない）。優先の台詞が来ると待っている非critical は破棄。2件以上待つときは表示時間を0.6倍（最短3.5秒）。破棄した場所の台詞は会話履歴に残す |
| 鎌の警告 | 中央の警告＋上部の通知＋字幕（初回）で同じ内容 | 中央の警告と音だけ。`survival.js` の `threatDirection` で正面・左・右・背後を判定し、文言と矢印、画面の縁の赤い脈動をその側に出す。初回の台詞は振り下ろしのあとに回す |
| 物置・避難小屋 | 戸口に怪異が立つと逃げ場がない。40秒ほど留まると死亡 | `gimmicks.js` の `updateShelter` と `shelterLeash`：入ってから20秒は建物中心から（建物の半径＋5.5m）の輪の外、戸口から6.8m以上離れた位置で待つ（`enemy.js` の leash に戸口を追加）。20秒で警告、30秒で解除し、音で居場所を知らせる。10秒以上外にいると計時をやり直す |
| 携帯の手がかり | 着信音のみ | 最初の着信で方向つきの通知、地図に「着信音？」の印。目的には加えない |
| 会話の枠 | 画面下の四分の一を覆う | 小さく、背景を薄く、位置を下げる。スマホでは幅を狭め、所在と履歴ボタンを省く。危険時は台詞だけに縮む。T の読む間停止を初回だけ案内 |
| 細部 | 二階の灯りがスマホで大きい／望遠鏡の表示が残る／ドラッグの案内が繰り返す | 灯りを0.62倍にして天井近くへ。望遠鏡を見たあとは調べる対象から外す。ドラッグの案内は1セッション2回まで・60秒あけて |
| 一時停止（スリープ） | ウィンドウの blur とマウス固定の解除で即座に停止 | blur は2.5秒続き、なおフォーカスがない場合だけ。固定の解除は0.4秒以内に戻らず、フォーカスがある場合（Esc）だけ。タブの非表示は即座。視点クリックで再固定 |
| 小物の画像 | なし | ゲーム内の3Dモデルを `tools/make-item-images.mjs` で PNG に（16点、manifest 付き）。記録画面と記録一覧で表示 |
