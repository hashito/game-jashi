# 邪視 ― 視線の山

匿名掲示板怪談「邪視」をもとにした、一人称のホラー探索・逃走ゲームです。ブラウザ内で動作し、標準の WebGL 描画に加えて、GPU が利用できない環境では同じ Three.js シーンを Canvas2D で投影します。

## v4 の遊び方

### v4.2 の追加

邪視は望遠鏡の最初から歩き続けます。建物には開閉できる引戸と間仕切りを追加しました。戸を閉めると視線は切れますが、三度のノックの後に開けられるため、その間に離れてください。看板は小さくし、深い霧の奥の地面・木・草は必要な範囲だけ生成します。

長靴・日誌・手鏡の接写と、小物5点の「細部を調べる」記録を追加しました。戸の軋み、間隔のずれたノック、息が途切れる間も加えています。操作は従来どおりE／タッチの「調べる」。詳細と制作記録は [v4.2改修仕様](docs/v4.2-improvements.md) を参照してください。

成人した主人公は、叔父・修司の別荘を片付けるため、古い DV カメラで二階の備品を撮っています。部屋からベランダへ出て望遠鏡を覗くと、風景、白い背中、こちらへ向く顔の順に17秒の実3D場面が流れます。最初は修司が同じ部屋に実在し、備品の撮影を頼んでから荷物を運び出します。その後、一階へ下りて無線機の同調を合わせると、無線と物音が続き、山道へ出る事情が少しずつ分かります。修司との無線を頼りに、サングラスと鍵束、西の物置のボトル、東の避難小屋のハンドルを探し、駐車場のゲートを開けて車を始動してください。

- **話者の見える会話**：修司は開始時に正面に立ち、階段を歩いて林道へ出ます。会話カードには肖像・名前・叔父という関係・対面／無線・所在を表示。発言は最低6秒、長文は最大14秒表示し、Enterで次へ、Tで読む間のゲーム停止／再開ができます。履歴も話者と所在を保持します。
- **雨戸・無線・呼び鐘**：雨戸は本当に通行と視線を遮り、両側から開け直せます。無線はつまみの信号強度を探して1.2秒安定させて固定。西の呼び鐘は音を出した地点へ怪異を誘い、材木の陰へ退くための仕掛けです。視認されている間は追跡が優先され、余韻は短時間だけ有効。再使用には25秒かかります。
- **杉林と怪異の形**：杉の樹冠を、幹・枝・透過した針葉の段に変更。顔と身体には同じ灰白色の皮膚を使い、単眼のまぶた、頬骨、奥の口腔、ずれた顎、不揃いの歯と爪を立体化しました。
- **音の位置と材質**：怪異・鐘・携帯は座標と視点に応じて定位し、壁と階の違いで音がこもります。木床・階段・落葉・砂利で足音が変わり、怪異が止まると足音も止まります。風、杉葉、喉、息、鎌の擦れ、無線の同調はWeb Audio合成です。v4.1の探し物の説明では、修司の案内音声を任意に再生できます（VOICEVOX:麒ヶ島宗麟）。物語の会話は字幕です。
- **探し物の見本（4.1）**：左上の「詳しく」で、実際の3Dモデルの見本・置き場所・目的・操作を表示します。説明中はゲームが止まり、8種類の音声案内も聞けます。地図は目標名と階を表示。近くでは壁・階・視線を考慮して対象を目立たせ、任意の記録は区別します。西の物置のボトル2本→東の小屋の赤い握りのハンドルという順序に、書き置きと台詞を統一しました。
- **二階と階段**：上階の部屋とベランダ、一階の机、階段の入口は同じ立体的な間取りにつながります。プレイヤーも怪異も歩いて階段を移動し、床や壁は視線・攻撃を遮ります。階ごとの地図と、階の違う目的地に向かう階段案内があります。
- **動きと知覚**：首が先に向き、身体が遅れて追従します。怪異は視野と遮蔽、歩行・走行音、ゲートや車の音で相手を認識します。見失うと最後に見聞きした地点へ進み、立ち止まって周囲を探します。姿の見えないプレイヤーの現在位置へ自動追従しません。足元に灯りを向けると、低い四足の姿勢へ移ります。
- **実際の追跡と死亡**：怪異は壁や木を避けて移動します。顔を画面の中央に捉え続けると心の余白を失い、至近距離では鎌を振り上げて攻撃します。振り上げは約1秒続き、その間は画面に警告が出ます。振り始めた向きは固定されるため、予備動作中に距離を取るか側面・背後へ抜けると回避できます。カメラの背後からは振り下ろしません。まともに3回受けると死亡します。
- **序盤の目撃（4.0.1）**：望遠鏡のあと、怪異は森から別荘の前まで歩いてくる姿がベランダから見えます。一階の無線を合わせるまでは家に入りませんが、ベランダで見つめ続けたり、長く立ち止まったりすると入ってきます。階段の入口には灯りと床の矢印が点き、画面右上の方角と距離は壁を通らない実際の経路をたどります。
- **やり直し（4.0.1）**：「記録からやり直す」は、壁から離れた開けた位置で、次の行き先の方向を向いて始まります。怪異は見えない遠くへ移り、最初の5秒は視線と鎌の影響を受けません。
- **会話の詰まり（4.0.2）**：台詞は「筋に関わる会話」「その場所の台詞」「怪異への反応」に分かれます。場所の台詞はその場を14m離れるか24秒たつと流れず、反応は6秒で消えます。場所と反応の台詞は2つまでしか待たせず、溜まっているときは1行を短めに表示します。筋に関わる会話は省かれず、流れなかった場所の台詞も会話の履歴に残ります。
- **鎌の向き（4.0.2）**：予備動作の警告に、怪異のいる側と逃げる方向（正面・左・右・背後）を表示し、その側の画面の縁が脈打ちます。警告は中央の表示と音だけで、字幕や上部の通知には重ねません。
- **一つ戸口の小屋（4.0.2）**：物置と避難小屋に入ってから20秒は、怪異は戸口から離れた輪の外で待ちます。20秒で「出口は一つだけ」と知らせ、30秒で輪が外れて入ってきます。少し外へ出ただけでは時計は戻りません。
- **携帯の手がかり（4.0.2）**：東の小屋の先で鳴る携帯は任意です。最初の着信音で方向を知らせ、記録（J）の地図に「着信音？」の印が付きます。目的には加えていません。
- **一時停止の条件（4.0.2）**：ほかのウィンドウへ2.5秒以上移ったとき、Esc でマウスの固定を外したとき（0.4秒で戻らない場合）、タブを隠したときに止まります。一瞬のフォーカス移動や固定の外れでは止まりません。画面をクリックするとマウスを再び固定します。
- **小物の画像（4.0.2）**：`node tools/make-item-images.mjs` がゲーム内の3Dモデルを撮影し、`dist/assets/items/` に保存します。記録画面と記録一覧で使います。
- **逃走の駆け引き**：走るとスタミナを消費します。木や建物で視線を切り、音を抑えると最後に認識された場所を探し始めます。目を閉じる動作は邪視を防ぎますが、鎌の攻撃からは守りません。
- **ボトルは二本**：8.5m以内で、木や壁に遮られていない相手に投げます。ひるむのは6.5秒だけで、その後は追跡を再開します。投げた容器は戻りません。
- **最後まで危険が続く**：ゲート操作に2.4秒、車の始動に4.2秒かかります。操作地点を離れたり被弾したりすると中断します。生きたまま始動を完了して初めて生還できます。
- **DV映像の異常**：粒子、走査線、画面の横ずれ、局所的な映像の欠けが危険に応じて変化します。攻撃時の顔、鎌の予備動作・振り抜き・戻り、投擲と飛沫も連動します。
- **7つの小物と3つの関連記録**：長靴、作業日誌、作業札、カセットケース、手鏡、鈴、橋の赤い紐を調べます。発見時は目に入る内容だけが記録されます。進行や別の小物の発見で、撮影した面の読み取りが進み、「追記あり」で知らせます。複数の物と古写真の記録がつながると、別の事情が見えてきます。無線と独り言は記録画面で読み返せます。
- **3つの生還結末**：圏外の携帯に出たか、関連記録をどれだけ整理したかで変化します。いずれも実際の脱出が必要です。死亡画面は生還結末と別に扱います。

地図・通路・建物・入口・橋・駐車場には共通の配置データを使います。閉じた駐車場にはゲート以外から入れず、開放後は車まで進めます。メニューや記録を読んでいる間はゲーム時間が止まります。

進行は同じブラウザの `localStorage` に保存します。危険な位置や重傷時には安全なチェックポイントを上書きしません。アカウントや端末をまたぐ同期はありません。v4 は v3 の安全な記録を移行します。既に第三段階以降へ進んだ記録には無線の再調整を要求しません。v1/v2 の途中記録は対象外です。獲得済みの生還結末は保持します。階・敵の認識状態・物語の段階・未読追記・再生途中の会話も保存と復元の対象です。

ビルド不要。`dist/` を静的 HTTP サーバーで配信します。ES modules を使うため `file://` で直接開く形式には対応していません。

- `dist/gimmicks.js`：無線の安定受信と鐘の再使用時間。
- `dist/dialogue.js`：話者、対面／無線と所在、読む速さ、会話カード。
- `dist/creature.js`：立体の単眼・口腔・顎・歯・身体・鎌と局所アニメーション。

- `dist/story.js`：段階的な会話、小物の発見・追記・既読、先取り取得時の順次開示。

## 制作と検証

`npm test` で実コントローラーの進行・保存・戦闘・音声を、`npm run check` で構文を検査します。`npm run smoke` はローカルEdge/Chromeを起動し、PC・スマホ縦横で見本、地図、停止、音声と画面内の収まりを検査します。`node tools/check-audio-render.mjs` は実際のWeb Audioグラフをオフライン描画し、5種類の効果音の音量と異常値を検査します。

素材は `media-queue.json` に先に列挙し、標準キューで依存関係・CPU/GPUの同時実行数・再開を管理します。`npm run media:plan` で計画を確認し、ローカル制作環境を用意した後 `npm run media:run` で制作します。手順と音声クレジットの引き継ぎは `tools/local-media-README.md`、改修意図は `docs/v4.1-improvements.md` を参照してください。公開前には `npm run assets:release` と `npm run build` を実行します。

## 原話と翻案

2008年1月17日投稿として再録されている怪談「邪視」を参照しています。初出スレッドそのものを検証したものではなく、実在の事件として確認した話でもありません。

- https://horror2ch.com/archives/2271232.html
- https://horror2ch.com/archives/2271232.html/2

再録では主人公が一階へ水を飲みに行った後、自室へ戻り、望遠鏡をベランダへ運びます。「二階」という直接の表記を引用したものではなく、本作で上階の部屋を二階として具体化しています。

山の別荘、望遠鏡、体を揺らす遅い接近と地面へ顔を下げる動き、白い無毛の姿、縦向きの一つ目、鎌、視線の精神的作用、サングラスによる軽減、周辺視野による対処、不浄を嫌う性質、圏外の着信を参照しました。原話の文章は転載せず、ゲーム内の文章は新たに作成しています。

成人の主人公、別荘の片付けとDV撮影、叔父の無線、葛西と杉田の記録、地形、ゲート、攻撃と追跡速度、道具の数値、死亡条件、3つの結末はゲーム用の創作です。原話では尿だけでは退散せず、成人の叔父の露出が決着に関わります。本作は、一時的にひるませる二本のボトルへ翻案しています。

### v4 の確認結果（2026-10-29）
